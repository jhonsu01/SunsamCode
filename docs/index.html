        Sunsam Mesh

        Un gateway local compatible con OpenAI y Anthropic. En la app eliges el modelo y eso es elegir la ruta: sunsam-auto, sunsam-local o sunsam-swarm.

        Del paper «Breaking the Token Ceiling»

        Dos técnicas de arXiv 2609.12303 adaptadas para que la red sea más eficiente.

        Conversión token → byte (End-Of-Token)

        Convierte la distribución del teacher sobre ~128K tokens en ~257 símbolos sin inferencias extra. Sirve para destilar modelos byte-level y para obtener etiquetas del router independientes del tokenizador.

        “isu”
        0.667
        “isk”
        0.167
        <eot>
        0.167

        Ejemplo «Tiramisu» del paper, reproducido en los tests.

        Bits-per-byte y bytes/s

        Tokens/s y la perplejidad por token no se pueden comparar entre modelos con tokenizadores distintos. BPB y bytes/s sí, así que el router elige máquina por calidad, latencia y velocidad reales. 

        coste = calidad·BPB + latencia·TTFT
      + velocidad·(1000 / bytes_s) + carga·inflight

        Empezar en 3 pasos

        Instala la app, levanta el gateway y añádelo como Custom provider.

        01

        Instala Sunsam Code

        Descarga el instalador de tu sistema desde la sección Descargas.

        02

        Arranca Sunsam Mesh

        Desde el código fuente, configura tus peers de la LAN:

        pnpm sunsam:mesh:init
pnpm sunsam:mesh
        03

        Añade el provider

        Model settings → Add provider → Base URL http://127.0.0.1:4141 y elige sunsam-auto.
